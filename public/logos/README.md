# Brand logos

`src/components/Integrations.tsx` shows one tile per integration. A tile uses, in this order:

1. a mark from the CC0 `simple-icons` package (WhatsApp, SAP, Google Sheets);
2. a file in this folder named `<key>.svg`, `<key>.png` or `<key>.webp`;
3. a neutral monogram.

Keys are the `key` values in `systems.channel` / `systems.tools` (`src/i18n/he.ts`).

Before the site goes public, check each company's brand guidelines or ask for permission,
and ask Hashavshevet for a higher-resolution file.
